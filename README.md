# Калькулятор налоговой нагрузки — Финалогика

Одностраничное веб-приложение для расчёта налоговой нагрузки ООО и ИП и сравнения УСН, ОСНО и АУСН.

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны. Для загрузки оформления Tailwind CSS, шрифта Inter и логотипа требуется интернет.

## Возможности

- Выбор ООО или ИП и системы налогообложения.
- Ввод выручки, расходов, количества сотрудников и зарплаты.
- Детализация налоговой нагрузки и сравнение систем налогообложения.
